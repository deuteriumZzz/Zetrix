# Активный frontend Zetrix

Состояние: 16 октября 2026 года. Продуктовый контекст находится в
[корневом README](../../../README.md), подробные следующие действия — в
[ROADMAP](../../../docs/ROADMAP.md).

## Точка входа и границы

`frontend/index.html` → `src/zetrix/main.ts`.
Это собственный лендинг Zetrix и локальный детерминированный сценарный прототип.
Vite собирает TypeScript и CSS. Сохранённый React-интерфейс предыдущего продукта
не монтируется этой точкой входа. Django API к демо не подключён.

Направление продукта: геополитические сценарии и их последствия для бизнеса.
Первая гипотеза пилота — команды международных закупок и торговые ограничения.
Текущее демо считает прямое воздействие на затраты. Оно не моделирует поведение
государств, компаний, рынков или каскад геополитических решений.

## Модули

| Файл | Ответственность |
| --- | --- |
| `globe.ts` | Canvas2D-проекция сферы из частиц, локальная текстура, drag, pause, reduced motion, offscreen suspension |
| `scenario.ts` | Типы и проверка вводных, пресеты, подписи, формула и ограничения |
| `workspace.ts` | Вкладки и клавиатура, поля, пересчёт, localStorage и экспорт сценария |
| `download.ts` | Локальное скачивание JSON |
| `main.ts` | Инициализация, жизненный цикл, меню и пилотный бриф |
| `motion.ts`, `motion-utils.ts`, `motion.css` | WAAPI, CSS motion, общая пауза, parallax, pointer, lifecycle |
| `styles.css` | Подключение модульных стилей страницы |
| `base.css`, `hero.css`, `approach.css` | Основа визуальной системы и вводные секции |
| `workspace.css`, `content.css`, `dialog.css`, `responsive.css` | Рабочее пространство, контент, диалог, адаптивность |

Расширенный motion-пакет реализован в коде: общий pause, staged hero,
pointer glow, scroll progress/parallax, сигнал по цепочке, stagger карточек,
индикатор вкладок, переход результата, меню/диалог и эффекты глобуса.
Точный статус и критерии проверки перечислены в разделе 6 ROADMAP.

Глобус использует `/globe/earth-blue-marble.jpg`. Маршруты декоративные;
они не представляют реальные поставки или live-события.

## Данные и расчёт

- `monthlyCost`: целое число USD от 1 до 1 000 000 000.
- `exposure`, `shock`: целые проценты от 0 до 100.
- `months`: один из горизонтов 1, 3, 6, 12 месяцев.
- `kind`: `trade`, `supply` или `energy`.

```text
additionalTotal = monthlyCost × exposure / 100 × shock / 100 × months
baselineTotal = monthlyCost × months
scenarioTotal = baselineTotal + additionalTotal
```

Все три варианта используют эту формулу с разными вводными и пояснениями.
Отображение округляет до центов; экспорт сохраняет вычисленную точность.
Параметры по умолчанию иллюстративны. Объёмы, доли и шоки постоянны на горизонте;
вероятности, FX, спрос, запасы и вторичные эффекты не учитываются.

Ключ локального сценария: `zetrix:scenario:v1`. При восстановлении структура
проверяется. JSON-бриф и экспорт скачиваются локально; заявки никуда не
отправляются. В активном лендинге нет live feed, AI engine, серверного хранения,
биллинга или подключения аккаунтов. Новое серверное ядро v2 реализовано отдельно,
см. [инструкцию backend](../../../docs/BACKEND.md); этот frontend его пока не вызывает. Текст интерфейса должен сохранять эти различия.

## Запуск и команды проверки

Из `frontend/`:

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
npm run build
npm run test -- src/zetrix/scenario.test.ts src/zetrix/workspace.test.js
```

Текущая итерация: сборка и 20 целевых тестов frontend прошли.
Новый визуальный просмотр ограничен недоступностью browser approval из-за лимита. Покрытие всего frontend не измерено.
В браузере ранее просмотрены desktop hero/workspace и mobile 390 px,
проверены меню, диалог, вкладки, ввод и save/restore. Ожидание скачивания
в браузерной автоматизации зависло; наличие корректного файла на диске
ещё нужно проверить. Payload покрыт интеграционными тестами.

После изменения motion проверить pause/reduced-motion, уход вкладки в фон,
offscreen suspension, очистку подписок при HMR, resize и мобильный touch.
Результаты чисел и фокус не должны зависеть от завершения анимации.

## Архив и публикация

`src/anadyr/` и `public/anadyr/` сохранены как материалы исследования референса.
Активная страница их не запрашивает. Архивный localizer записывает
`src/anadyr/reference.html`, чтобы не перезаписывать Zetrix.
Перед публичной поставкой проверить состав `dist`: Vite может копировать
неиспользуемые файлы из `public`, включая архив. Исключить архив из выпускного
артефакта и проверить права на используемые изображения и шрифты.

Реальный запуск пилота потребует отдельной реализации источников, модели,
backend и правил работы с клиентскими данными. План находится в ROADMAP.
