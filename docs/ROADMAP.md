# Zetrix — план развития продукта и motion-дизайна

Обновлено: 31 октября 2026 года. Это рабочий план, а не обещание сроков.
Подробная спецификация первой версии: [MVP, кабинет и backend](MVP.md).
Лендинг: `frontend/index.html` и `frontend/src/zetrix/`; кабинет:
`frontend/app/index.html` и `frontend/src/cabinet/`.
При расхождении планов с кодом сначала фиксируем факт, затем обновляем документ.

## 1. Принятое направление

**Zetrix — сценарный анализ геополитических изменений и последствий для бизнеса.**
Начальная гипотеза аудитории: команды международных закупок и финансового
планирования, которым нужно оценивать влияние торговых ограничений на расходы.
Первая задача: сравнить исходные затраты и несколько вариантов удорожания,
показать зависимость от поставок, проверить доступные варианты действий.

- Свой бренд, язык интерфейса и визуальная система; ориентир по качеству — технологичные 3D-лендинги.
- Глобус должен постепенно стать способом исследовать связи, события и сценарии.
- Каждый вывод должен раскрывать вводные, источники, модель и её ограничения.
- Вероятность события и величина последствий — разные величины; не смешивать их.
- Не называть иллюстративный расчёт AI-прогнозом или доказанной геополитической симуляцией.
- Масштабировать продукт после подтверждения ценности узкой задачи.
- **Решение владельца от 31 октября 2026:** долгосрочная цель — стать прямым
  конкурентом платформ сценарного моделирования геополитики, в первую очередь
  Anadyr Horizon. Это цель, а не текущее состояние: разрыв, путь и правила
  формулировок — в разделе 14 (этап H). Ограничения на формулировки выше
  остаются в силе, пока соответствующие проверки не пройдены.

## 6. Motion-направление: как сделать Zetrix узнаваемым

Идея визуального языка: **событие → распространяющийся сигнал → изменение решения**.
Анимация связывает части рассказа и показывает причинность. Декоративные
потоки до подключения данных явно остаются художественной частью интерфейса.

### Текущий пакет — реализован в коде

| Эффект | Назначение | Проверка готовности |
| --- | --- | --- |
| Поэтапное появление hero | Сначала вопрос, затем контекст и действие | Текст не остаётся скрытым при сбое JS |
| Появление глобуса и мягкая атмосфера | Создать глубину первого экрана | Нет скачка размера canvas и засветки текста |
| Тонкие орбиты и движущиеся сигналы | Подчеркнуть сеть зависимостей | Не изображают реальные данные |
| Подсветка от указателя | Реакция среды на пользователя | Только fine pointer; без зависимости на touch |
| Небольшой parallax первого экрана | Разделить глубину глобуса и текста | Отключается при pause/reduced motion |
| Индикатор прогресса страницы | Ориентация в длинной истории | Не перекрывает навигацию и фокус |
| Проходящий сигнал по цепочке | Связать событие, зависимость, последствия | Порядок соответствует смыслу блоков |
| Stagger карточек | Управлять порядком чтения | Без длительного ожидания и layout shift |
| Подвижный индикатор вкладок | Показать смену сценария | Не отстаёт после клавиатурного переключения |
| Переход результатов расчёта | Подсветить изменение после ввода | Итог доступен сразу, анимация не меняет числа |
| Открытие меню и диалога | Сохранить пространственный контекст | Фокус и Escape работают независимо от эффекта |
| Общий контроль движения | Передать управление пользователю | Останавливает всю декоративную анимацию |

### Общие правила motion

- Использовать общие duration/easing tokens, а не случайные значения по компонентам.
- Быстрая обратная связь: ориентир 120–220 ms; переходы панелей 220–420 ms.
- Сценические reveal: ориентир 500–900 ms; окончательные значения выбирать по просмотру.
- Не задерживать доступ к CTA и содержимому до окончания постановочного вступления.
- По возможности анимировать transform/opacity; избегать постоянного layout/paint.
- Ограничивать DPR, число частиц и эффекты на малых экранах по измерению.
- Останавливать постоянные циклы вне viewport и в скрытой вкладке.
- При reduced motion убирать вращение, parallax, sweep и пространственные перемещения.
- Ручная пауза должна распространяться на CSS, canvas и JS-анимации.
- Оставлять hover дополнительным эффектом: все действия доступны без мыши.
- Не применять scroll hijacking, мигающий текст и имитацию загрузки/вычислений.
- Не включать звук автоматически; звуковое оформление пока вне объёма.
- Числа для screen reader обновлять по действию, а не на каждом кадре tween.
- Для каждого эффекта фиксировать trigger, duration, easing, reduced-state и cleanup.

**Предлагаемые измеримые бюджеты:** отсутствие непрерывного RAF при паузе/скрытии,
отсутствие CLS от анимаций, стабильная работа на согласованном мобильном устройстве.
Целевой FPS и допустимую CPU-нагрузку утвердить после профилирования; пока не заявлять 60 FPS.

## 9. Предлагаемые контракты данных — ещё не API

| Сущность | Минимальные поля | Инвариант |
| --- | --- | --- |
| Source | id, publisher, url, license, retrieved_at, version, checksum | Происхождение доступно, права проверены |
| Evidence | id, source_id, locator, assertion, valid_from, review_status | Утверждение отличается от интерпретации |
| Event | id, kind, regions, sectors, effective_at, evidence_ids, status | Дата публикации не подменяет дату действия |
| Exposure | id, company_id, region, supplier, category, amount, currency, period | Единицы и период обязательны |

| Dependency | from_id, to_id, relation, weight, unit, evidence_ids | Вес имеет определённый экономический смысл |

### Гипотезы отличия — не подтверждены

- Прозрачная формула и открытая методология: результат проверяется вручную.
- Русскоязычный интерфейс для команд, которым нужен именно он.
- Узкий вход через закупки и затраты, затем расширение на другие решения.
- Доступность без заявки и открытый код.

Каждую проверить на интервью (этап B). Пока клиент не подтвердил, это
гипотеза, а не преимущество.

### Правила

- Сравнивать только по публичным источникам, с датой и ссылкой. Заявления

  считать подтверждёнными.
- Не копировать тексты, дизайн, изображения и код. Архив референса остаётся
  вне репозитория (`.gitignore`).
- Не называть расчёт симуляцией, AI-прогнозом или аналогом конкурента, пока не
  пройдены проверки строк «Модель» и «Подтверждение качества».
